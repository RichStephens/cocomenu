## [1.0.0] 2026-10-14

- Lists the machine-language and BASIC programs on the disk it booted from and runs the one picked
- A machine-language program returns to the menu when it exits; after a BASIC program, type `DOS`
- The top rule shows the disk's HDB-DOS title
- On an HDB-DOS multi-disk image, left and right switch disks, the bottom rule reads `</>=DISK x OF y`, and the menu comes back on the disk a program was run from
- BREAK leaves the menu for BASIC on the current disk
